# Galaxy CNN Web App

This app uses a trained CNN model to classify galaxy images.

## Instructions

1. Save your trained model as `galaxy_cnn_model.h5` and place it in this directory.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app locally with:
   ```bash
   streamlit run streamlit_app.py
   ```

To deploy:
- Push to GitHub and connect to Streamlit Cloud: https://streamlit.io/cloud
